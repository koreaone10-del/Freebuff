# Freebuff — منصة AI مفتوحة مع رادار طيران مباشر

واجهة عربية RTL تعمل على Node.js ويمكن نشرها على Render. التشغيل الأساسي لا يحتاج مفاتيح API يضيفها المستخدم. بعض عمليات الربط الاختيارية بحسابات خارجية (مثل GitHub أو Facebook) قد تتطلب رمز الحساب نفسه، لكنها ليست شرطاً لتشغيل المنصة. تعتمد الصور على شبكة AI Horde التطوعية، والرادار على شبكات ADS-B المفتوحة، والخريطة على Leaflet وOpenStreetMap.

## الوظائف الأساسية

- دردشة عبر LLM7 وKilo على نماذج مجانية متاحة دون مفتاح؛ توفر النماذج وحدودها قد يتغيران، لذلك لا يوجد ضمان توافر دائم أو رصيد غير محدود.
- تحليل الصور عبر نموذج رؤية مجاني من Kilo عند توافره.
- النطق الصوتي يستخدم خدمة ويب عامة غير مضمونة؛ أما تفريغ ملفات الصوت إلى نص فغير مفعّل في هذه النسخة لأن المسارات المستقرة التي تم التحقق منها تتطلب مفاتيح.
- توليد صور عبر AI Horde باستخدام الطلب المجهول العام، دون مفتاح شخصي. الطلبات تدخل طابور GPU تطوعي وقد تتأخر أو تنتهي دون نتيجة عند غياب عامل مناسب.
- استوديو فيديو يركّب فيديو من صور ثابتة وتعليق صوتي وموسيقى وحركة داخل المتصفح. هذا ليس توليداً أصلياً لحركة الفيديو بواسطة نموذج Text-to-Video.
- مركز طيران بخريطة Leaflet حقيقية، وبيانات ADS-B من adsb.lol وAirplanes.live مع OpenSky كبديل.
- سجل محادثات محلي في المتصفح، مع إمكان التصدير والاستيراد.

## التشغيل والنشر

المتطلبات: Node.js 20 أو أحدث.

```bash
npm install
npm run check
npm start
```

افتح `http://localhost:10000`. على Render استخدم `render.yaml` أو اضبط: Build Command=`npm install`، Start Command=`npm start`، Health Check Path=`/api/health`. لا توجد مفاتيح إلزامية.

## الخدمات العامة ومصادرها

- [AI Horde API](https://aihorde.net/api) و[دليل الاستخدام](https://horde.stablehorde.net/docs/image/): شبكة حوسبة تطوعية لتوليد الصور. الاستخدام المجهول مجاني بأولوية أقل، والتوفر يعتمد على العمال المتصلين والطابور.
- [Kilo AI Gateway](https://kilo.ai/docs/gateway/authentication): يسمح بطلبات مجهولة للنماذج المجانية فقط، مع حد معلن حسب عنوان IP. أسماء النماذج المجانية تتغير.
- [LLM7](https://api.llm7.io): بوابة نماذج عامة؛ التوفر ومعدل الطلبات يتغيران.
- [adsb.lol API](https://api.adsb.lol/docs): واجهة ADS-B عامة مفتوحة، ترخيص البيانات ODbL.
- [Airplanes.live](https://airplanes.live/): مجمّع ADS-B/MLAT مجتمعي.
- [OpenSky Network](https://opensky-network.org/): مصدر احتياطي، وقد يفرض قيوداً على الطلبات المجهولة.
- [Leaflet](https://leafletjs.com/): مكتبة خرائط مفتوحة المصدر.
- [OpenStreetMap](https://www.openstreetmap.org/): بلاطات الخريطة مع الإسناد الإلزامي. خوادم البلاطات العامة best-effort وليست خدمة مضمونة SLA.

ملاحظة ترخيص: التطبيق ومكتباته مفتوحة المصدر، لكن واجهات الاستدلال العامة ليست كلها مشاريع مفتوحة المصدر، كما أن تراخيص أوزان النماذج تختلف. لا تُرسل بيانات خاصة أو حساسة إلى خدمات مجانية عامة.

## حدود يجب معرفتها

1. «بلا مفاتيح» لا تعني «غير محدود». الخدمات العامة قد تضع طوابير أو حدوداً أو تتوقف مؤقتاً، كما أن بعض بوابات الاستدلال ليست مشاريع مفتوحة المصدر رغم أنها تتيح نماذج مفتوحة الأوزان بلا مفتاح.
2. Render Free ليس خادماً مناسباً لتشغيل نماذج صور أو فيديو كبيرة محلياً، كما أن ملفاته المحلية مؤقتة.
3. GitHub Actions القياسي لا يوفّر GPU مجانياً مستمراً؛ دوره هنا اختبارات CI فقط.
4. لا يوجد في هذه الحزمة مولّد Text-to-Video داخلي مثبت على Render. نماذج مثل [Wan](https://github.com/Wan-Video/Wan2.1) و[LTX-2](https://github.com/Lightricks/LTX-2) مفتوحة الأوزان/الكود بشروط تراخيصها، لكنها تحتاج GPU فعلياً وذاكرة فيديو كافية؛ لا نخفي ذلك خلف شريط تقدم وهمي.
5. بيانات ADS-B ليست تغطية كاملة لكل الطائرات، وقد لا تتضمن الوجهة أو التسجيل أو النوع. تصنيف «داخلة/خارجة» تقدير مبني على المسار والإحداثيات وليس معلومة رسمية من مراقبة الحركة الجوية.
6. سجل الجلسات محلي في المتصفح وليس مزامنة سحابية. لا تعتمد على مساحة Render المؤقتة لحفظ الفيديوهات أو الملفات.

## الاختبارات

```bash
npm run check
PORT=18765 npm start
curl http://127.0.0.1:18765/api/health

```

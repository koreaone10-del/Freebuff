# نبراس AI — ذكاء اصطناعي فخم مجانًا وبلا مفاتيح

واجهة عربية (RTL) كاملة للذكاء الاصطناعي تعمل على Cloudflare Workers **بدون أي مفتاح API أو توكن أو حساب**، مع دردشة بثّ حي، بحث عميق بمصادر حقيقية، تحليل مواقع، قراءة كل أنواع الملفات، رؤية، تفريغ صوتي، توليد صور، و**استوديو فيديو** كامل.

## المزايا

| الميزة | التفاصيل |
| --- | --- |
| 💬 دردشة ذكية | بثّ حرفي (SSE) + عرض التفكير الداخلي، جلسات غير محدودة محفوظة في IndexedDB، ضغط سياق تلقائي للجلسات الطويلة |
| 🔎 بحث عميق | خطة بحث من النموذج → استعلامات متعددة → قراءة المصادر → تقرير معزّو المصادر 【n】 |
| 🌐 تحليل مواقع | قراءة الصفحة عبر قارئ ويب مجاني وتحليلها تحليلًا معمّقًا |
| 📎 كل الملفات | صور، PDF، Word، Excel، ZIP، كود، فيديو (بتقطيع لقطات)، صوت (تفريغ Whisper) |
| 👁️ رؤية | تحليل الصور والفيديو بموديل رؤية مجاني |
| 🎨 توليد صور | صور Flux مجانية مع إعادة توليد وتنزيل |
| 🎬 استوديو فيديو | سيناريو ومشاهد من نموذج مجاني → صور مولّدة → تعليق صوتي عربي + موسيقى مولّدة → مونتاج وتسجيل على Canvas → ملف WebM قابل للتنزيل |

## المزوّدون المجانيون (بلا مفاتيح)

- **Pollinations** — `openai-fast`
- **LLM7** — `minimax-m2.7`، `codestral-latest`
- **Kilo Gateway** — `kilo-auto/free`، `nemotron-3-ultra-550b`، `north-mini-code`، `nemotron-3.5-super-vl`
- **OVH AI** — `gpt-oss-120b`، `Qwen3.5-397B`، `Llama-3.3-70B`، `Mistral-Small-3.2`، `Qwen2.5-VL-72B` (رؤية)، `whisper-large-v3-turbo` (صوت)

يوزّع الخادم الطلبات بين المزوّدين بالتناوب مع تهدئة (cooldown) لكل مزوّد، فإن فشل أحدهم انتقل تلقائيًا للتالي.

## نقاط الوصول

| المسار | الوصف |
| --- | --- |
| `GET /api/health` | حالة المزوّدين الحيّة وتهدئتهم |
| `GET /api/models` | قائمة الموديلات المتاحة |
| `POST /api/chat` | دردشة (بثّ SSE أو JSON) |
| `GET /api/search?q=` | بحث ويب (Bing ثم DuckDuckGo Lite ثم Jina) |
| `GET /api/fetchurl?url=` | قراءة صفحة كنص |
| `POST /api/vision` | تحليل صور/لقطات فيديو |
| `POST /api/audio` | تفريغ صوتي |
| `POST /api/video/plan` | خطة فيديو: عنوان + مشاهد (سرد، كابشن، وصف صورة) |
| `GET /api/tts?text=&lang=` | نطق مجاني (MP3) للتعليق الصوتي |

## التشغيل محليًا

```bash
npm install --no-save wrangler
npx wrangler dev --local
```

أو النشر على Cloudflare:

```bash
npx wrangler deploy
```

## استوديو الفيديو

مستوحى من فلسفة [OpenMontage](https://github.com/calesthio/OpenMontage) في تحويل الطلب إلى خطة إنتاج ثم تنفيذها (تخطيط → مشاهد → أصول → مونتاج → تسليم)، لكنه يعمل بالكامل في المتصفح وبلا مفاتيح:

1. **خطة**: `/api/video/plan` يطلب من نموذج مجاني JSON فيه العنوان والمشاهد وسرد كل مشهد ووصف صورته بالإنجليزية.
2. **صور**: كل مشهد يُرسم بـ Flux من Pollinations بمقاس الفيديو المختار (16:9 / 9:16 / 1:1).
3. **صوت**: تعليق عربي لكل مشهد عبر `/api/tts`، وموسيقى خلفية مولّدة بـ Web Audio (بدون ملفات خارجية).
4. **مونتاج**: Canvas مع Ken Burns، انتقالات تلاشي، كابشن عربي، بطاقة بداية ونهاية، وشريط تقدّم.
5. **تسليم**: `MediaRecorder` يسجّل الفيديو والصوت معًا ويُنتج ملف WebM للتنزيل أو إضافته للمحادثة.

> ملاحظة: التسجيل يجري بالزمن الحقيقي، ففيديو 30 ثانية يحتاج نحو 30 ثانية بعد تجهيز الصور والأصوات. OpenMontage نفسه يحتاج Python وFFmpeg للتشغيل المحلي، ولا يمكن تشغيله داخل Worker؛ لذلك استُخدمت نفس منهجية خط الأنابيب بأدوات المتصفح المجانية.

## الخصوصية

لا حسابات ولا تتبّع: المحادثات تُخزَّن في IndexedDB داخل متصفحك فقط، والإعدادات في `localStorage`.

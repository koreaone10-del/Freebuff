# CHIBANI AI — منصة واحدة للذكاء الاصطناعي المجاني

واجهة عربية (RTL) كاملة تعمل على **Cloudflare Workers + الأصول الثابتة** بلا أي مفتاح مدفوع: دردشة بثّ حي، بحث موثّق بالمصادر، تحليل مواقع، قراءة الملفات، رؤية، تفريغ صوتي، توليد صور، واستوديو فيديو كامل داخل المتصفح.

## المزايا

| الميزة | التفاصيل |
| --- | --- |
| 💬 دردشة ذكية | بثّ حرفي (SSE) + عرض التفكير الداخلي، وتذكير بحدود الموثوقية |
| 🔎 بحث عميق | بحث ويب → قراءة الصفحات فعلياً → إجابة باستشهادات مرقّمة `[n]` مع قائمة المصادر |
| 🌐 تحليل مواقع | قراءة الصفحة عبر قارئ ويب مجاني ثم تقرير: الهدف، الجمهور، البنية، القوة والضعف، التوصيات |
| 📎 قراءة الملفات | PDF، Word (docx)، Excel/CSV، ZIP، النصوص والشيفرة، مع حدّ حجم واضح لكل نوع |
| 👁️ رؤية | وصف الصور المرفقة عبر نموذج رؤية مجاني |
| 🎧 تفريغ صوتي | تحويل الملفات الصوتية إلى نص عبر Whisper المجاني |
| 🎨 توليد صور | Flux عبر `/api/image` مع تنزيل ونسخة بديلة وتكبير |
| 🛠️ أدوات حيّة | تنسيق JSON، Base64، ترميز/فك URL، استخراج الروابط، إحصاء النص، قراءة صفحة كاملة |
| 🎬 استوديو فيديو | خطة مشاهد → صور مولّدة → تعليق عربي → موسيقى مولّدة → تسجيل Canvas → MP4 أو WebM |
| 🎯 مجالات خبرة | أربع بطاقات (برمجة، تحليل، تعليم، أعمال) تُحقن في توجيه النظام لكل رد |
| 👤 حساب محلي | تسجيل بالبريد أو الهاتف ورمز سري مُشتقّ بـ PBKDF2 — يبقى في متصفحك |
| 🔌 ربط الخدمات | GitHub وRender وFacebook برموز يملكها المستخدم، عبر وسيط محصور في الخادم |

## المزوّدون المجانيون (بلا مفاتيح)

- **Pollinations** — `openai-fast`
- **LLM7** — `minimax-m2.7`، `codestral-latest`
- **Kilo Gateway** — `kilo-auto/free`، `nemotron-3-ultra-550b`، `north-mini-code`، `nemotron-3.5-super-vl`
- **OVH AI** — `gpt-oss-120b`، `Qwen3.5-397B`، `Llama-3.3-70B`، `Mistral-Small-3.2`، `Qwen2.5-VL-72B` (رؤية)، `whisper-large-v3-turbo` (صوت)

يوزّع الخادم الطلبات بين المزوّدين بالتناوب مع تهدئة (cooldown) لكل مزوّد، فإن فشل أحدهم انتقل تلقائياً إلى التالي.

## بوابة Respan (اختيار، بمفتاح)

مسار واحد متوافق مع OpenAI يمرّ ببوابة Respan، وكل طلب عبرها يُسجَّل تلقائياً في Respan (بلا SDK). لا تُفعَّل إلا بوجود المفتاح على الخادم، بدون أي تغيير في بقية المزوّدين:

| المتغيّر | الوصف |
| --- | --- |
| `RESPAN_API_KEY` | مفتاح Respan السري. غيابه أو فراغه يعني بقاء التوزيع المجاني كما هو |
| `RESPAN_MODEL` | معرّف النموذج على البوابة (اختياري). الافتراضي `gpt-5.5` |

- **الترتيب**: عند وجود المفتاح يبدأ الوضع «تلقائي» بالبوابة (`https://api.respan.ai/api/chat/completions`) ثم ينتقل تلقائياً إلى المزوّدين المجانيين عند أي فشل (401 بلا رصيد، 403 مفتاح خاطئ، 429، انقطاع).
- **اختيار صريح**: يظهر النموذج في `/api/models` باسم `respan::<model>`، ويُقبل الطلب `{"model":"respan::claude-sonnet-4-5-20250929"}` مباشرة؛ وغياب المفتاح يعيده إلى المسار المجاني.
- **الوسوم**: كل طلب بوابة يحمل `metadata: { app: "chibani-ai", workflow: "chat" }`، وترويسة الاستجابة `X-Respan-Log-Id` تشير إلى سجله في Respan.
- **التفعيل**: محلياً انسخ `.env.example` إلى `.dev.vars` وضع المفتاح فيه (المتغيّرات نفسها في `.env` عند التشغيل خارج wrangler)؛ عند النشر `npx wrangler secret put RESPAN_API_KEY`.
- **التحقق**: `GET /api/health` يظهر فيه صف `respan::<model>` وحقل `respan: true`، ثم افتح Logs في platform.respan.ai لرؤية الطلب نفسه.

### ملاحظة صریحة حول المفاتيح المجانیة

- لا توجد مصدر مفتوح مجاني بمثل هذه الكفاءة لـ **nano-banana** (توليد صور ذكية بالكامل) بهذا التكلفة والجودة المتاحة الآن، والبحث في الملفات العامة الأخرى لا يملكه أبداً: **Horde** هو المزوّد الثاني (بلا مفتاح) لخدمة `provider=auto`، و**Pollinations** هو الأول، و**Kilo Gateway** و**OVH AI** مزوّدون إضافيان.
- **Horde** (aihorde.net) لا يتطلب مفتاحاً يدخله المتصفح أو الإعداد، ويُستخدم فيه `apikey: 0000000000` كرمز وهمي (أيّ مفتاح يُدخله المستخدم لا يُستخدم في العملية)، ويُحَدّد أبعاد الصور بـ **768** على أحد الضلعين الأطول، ثم يمدّها المتصفح.
- **Pollinations** (`gen.pollinations.ai`) يُوجّه طلباً لـ `https://image.pollinations.ai/prompt/...`، وبدون مفتاح يُعيد **`401`** (ليس `429`): ليس حصة مُمتلئة، بل مفتاح غير صالح. عند الضغط على **Gen**، تُولد الصورة فوراً وتبقى معروضة في المتصفح، ولا يرفع أي شيء خلفياً.
- جميع المزوّدين مجانيون مع الرفع والتمرير والخلفية في المتصفح فقط، و**لا يتم تسجيل أي مفتاح أو رمز في أي ملف أو في بيئة التشغيل**.

## نقاط الوصول

| المسار | الوصف |
| --- | --- |
| `GET /api/health` | حالة المزوّدين الحيّة ومدة التهدئة |
| `GET /api/models` | قائمة النماذج المتاحة |
| `POST /api/chat` | دردشة (بثّ SSE أو JSON) |
| `GET /api/search?q=` | بحث ويب (Bing ثم DuckDuckGo Lite ثم Jina) |
| `GET /api/fetchurl?url=` | قراءة صفحة كنص |
| `GET /api/image?prompt=&width=&height=&seed=` | توليد صورة (Flux ثم Turbo) وتمريرها من نفس الأصل |
| `POST /api/vision` | تحليل الصور |
| `POST /api/audio` | تفريغ صوتي |
| `POST /api/video/plan` | خطة فيديو: عنوان، `hero` (وصف لقطة تأسيسية إنجليزية)، ومشاهد (سرد، كابشن، وصف صورة) |
| `GET /api/tts?text=&lang=` | نطق مجاني (MP3) للتعليق الصوتي |
| `POST /api/connect` | وسيط ربط محصور: مسارات مسموحة فقط لـ GitHub وRender وFacebook |
| `POST /api/hunt` | مسح مصادر مفتوحة: يبحث `query` في **Facecheck** (بحث الصورة/الوجه)، **Robin** (السجلات الشخصية والاتصالات)، و**Airplanes** (قاعدة بيانات الطيران والرحلات)، ويُعيد النتائج مع وصف عربي وروابط الفتح المباشر. |

### مصادر البحث المفتوحة (OSINT)

| المصدر | النطاق | الوصف |
| --- | --- | --- |
| Facecheck | `facecheck.id` | بحث صورة بواسطة الوجه ومطابقة الصور في الصور والفيbes والتواصل — وصفة واحدة تعرض الصفحة أو وحدة البحث المباشرة. |
| Robin | `robin.me` | سجل شخصي واتصالات مجانية: ابحث عن الشخص عبر الصورة أو الاسم، وشاهد السجلات والبيانات المتاحة. |
| Airplanes | `airplanes.live` | قاعدة بيانات الطيران والرحلات: تحقق من رحلات الطائرات، والشركات، والدخول الجوي، والنقاط الجوية. |

### أمان `/api/connect`

- لا يُخزَّن أي رمز على الخادم ولا يُسجَّل؛ يُمرَّر من ترويسة `x-cb-token` إلى المزوّد في الطلب نفسه.
- الخدمة تحدِّد المضيف، والمسار يجب أن يبدأ بأحد البادئات المسموحة (`/user`, `/gists`, `/services`, `/owners`, `/me`).
- تُرفض المسارات التي تحتوي `..` أو `//` أو `?` أو `#` أو `\`، والطرق غير GET/POST.
- للاستجابة موحَّدة: `{ ok, status, data }` أو `{ ok: false, status, error }`.

## التشغيل المحلي والنشر

```bash
# تثبيت الاعتماد الوحيد المطلوب للتشغيل المحلي
npm install --no-save wrangler

# خادم محلي على http://127.0.0.1:8787
npx wrangler dev --port 8787 --ip 127.0.0.1

# نشر إلى Cloudflare Workers (يتطلب تسجيل دخول Wrangler)
npx wrangler deploy
```

`wrangler.toml` و`deploy.json` يصفان المشروع: `main = worker.js` مع `assets.directory = ./public` وربط `ASSETS`.

## استوديو الفيديو

مستوحى من منهجية [OpenMontage](https://github.com/calesthio/OpenMontage) في تحويل الطلب إلى خطة إنتاج ثم تنفيذها (تخطيط → مشاهد → أصول → مونتاج → تسليم)، لكنه يعمل بالكامل في المتصفح وبلا مفاتيح:

1. **خطة**: `/api/video/plan` يطلب JSON فيه العنوان والمشاهد وسرد كل مشهد ووصف صورته بالإنجليزية.
2. **صور** — وضعان:
   - **⚡ صورة واحدة وزوايا متعددة** (الافتراضي): تُولَّد صورة أساسية واحدة واسعة (حتى 1600px) من حقل `hero`، ثم يُستخرج لكل مشهد **لقطة كاميرا مختلفة**: نافذة قصّ في منطقة أخرى، انعكاس، ميل خفيف، وتدرّج لوني. حصة صور واحدة بدل عدد المشاهد، والزوايا جاهزة في أجزاء من الثانية.
   - **صورة لكل مشهد**: تُرسم كل صورة عبر `/api/image` بمقاس الفيديو (16:9 / 9:16 / 1:1) من وصف مشهدها؛ تنوّع أعلى لكنه ينتظر حصة كل مشهد.

   الخدمة المجانية تسمح بصورة كل 45 ثانية لكل عنوان IP، فيعرض الاستوديو **عدّاد انتظار** بدل الفشل، ويرى الرد 429 و`x-retry-after` ويعيد المحاولة، وعند نفاد الحصة يستخدم تنويعاً بصرياً بدل خلفية مسطَّحة، ويذكر ذلك في سطر الحالة.
3. **صوت**: تعليق عربي لكل مشهد عبر `/api/tts`، وموسيقى خلفية مولَّدة بـ Web Audio (بلا ملفات خارجية)، على مرساة زمنية واحدة تمنع أي إزاحة بين الصوت والصورة.
4. **مونتاج**: Canvas بحركة Ken Burns، كابشن عربي، وبطاقة عنوان في البداية.
5. **تسليم**: `MediaRecorder` يسجِّل الفيديو والصوت معاً وينتج **MP4 (H.264 + AAC)** أو **WebM** تلقائياً، مع **فهرس مشاهد** في نتيجة الاستوديو وفي الشريط الجانبي للتنقل الفوري، وزر تنزيل وإرسال إلى المحادثة.

> تم التحقق من المسار كاملاً في Chromium حديث: خرج ملف `video/mp4` بمقاس 1280×720 مع مسار صوتي AAC، ومدته صُحَّحت لتطابق خط الزمن، وظهرت علامات مشاهد تعمل بالنقر داخل المشغِّل وفي الشريط الجانبي. وفي وضع «صورة واحدة» أُنتج فيديو ستة مشاهد في **105 ثوانٍ** شاملة التسجيل (57 ثانية) — كانت الطريق السابقة تحتاج نحو **360 ثانية** لأنها تنتظر حصة صورة لكل مشهد — وكانت اللقطات الست زوايا مختلفة من صورة واحدة حقيقية لا خلفيات بديلة.

### صيغة الإخراج

المحرِّك يجرِّب الحاويات بترتيب أولوية ثابت: `video/mp4` بمجموعات ترميز H.264/AAC ← ثم `video/webm` (VP9 ثم VP8). أول صيغة يدعمها المتصفح فعلياً هي التي تُستخدم، ويُبنى امتداد التنزيل على `rec.mimeType`.

- **Chrome 126+ وEdge وSafari**: MP4 مباشرة، جاهز للنشر والمشاركة دون تحويل.
- **Firefox** (لا يملك مُرمِّز H.264 في `MediaRecorder`): WebM تلقائياً مع تنبيه واضح في الواجهة.

### تصحيح المدة والطوابع الزمنية (`public/mp4.js`)

`MediaRecorder` ينتج MP4 مجزَّأ (fMP4) ويكتب `mvhd.duration = 0` لأن المدة لا تُعرف إلا بعد انتهاء التسجيل، فتعرض بعض المشغِّلات والمحرِّرات الطول ٠:٠٠ أو مدة خاطئة أو ترفض الاستيراد. بعد التسجيل يقرأ `VD_MP4.fixDuration` بنية الملف ويحسب المدة الحقيقية من مجموع مدد العينات في `trun` (أو `default_sample_duration` في `tfhd` عند غيابها)، ثم يكتبها في مواضعها:

- `mvhd.duration` و`mehd.fragment_duration` بمقياس زمن الفيلم.
- `tkhd.duration` لكل مسار بمقياس الفيلم، و`mdhd.duration` بمقياس المسار.
- `tfdt`: إن بدأ التسجيل بإزاحة، تُطرح قيمة أول طابع من كل المسارات ليبدأ الفيلم عند الصفر.

التعديل يجري **في مكانه** بلا حذف أو إدراج بايتات: الحجم ثابت ولا تتغيَّر أي إزاحة، فلا تتلف المقاطع.

> ما لا يفعله: لا يُنشئ `sidx` أو `mfra`، ولا يحوِّل الفيديو، ولا يمسَّ بيانات الصورة أو الصوت. ولو كان الملف غير مجزَّأ أو كانت مدته صحيحة أصلاً يُترك كما هو.

### تصحيح مدة WebM (`public/webm.js`)

في المتصفحات التي لا تسجِّل MP4 يخرج WebM مكتوباً بثَّاً حيَّاً: `Segment` بحجم مجهول وبلا عنصر `Duration` في `Info`، فتعرض مشغِّلات كثيرة المدة `∞` أو `0:00` ويتعطَّل شريط التقدُّم. `VD_WEBM.fixDuration` يعالج ذلك:

1. **حساب المدة** من الطوابع الحقيقية: `Timecode` لكل `Cluster` + الطابع النسبي لكل `Block`، ثم إضافة مدة الإطار الأخير.
2. **إن وُجِد `Duration`** يُكتب في مكانه بلا أي إزاحة.
3. **إن لم يوجد** يُدرج 11 بايت داخل `Info`، ويُحدَّث حجم `Info` (و`Segment` إن كان حجمه معروفاً) بنفس عرض حقل الحجم، وتُنقَل كل إزاحة متأثرة في `SeekHead` و`Cues` بمقدار الإدراج. ولو لم يتَّسع حقل الإزاحة يُلغَى التعديل بدل إنتاج ملف تالف.

> ما لا يفعله: لا يُنشئ `Cues` للملفات الحيَّة ولا يعيد بناء `SeekHead`. وفي الاستوديو يعرض `VD_WEBM.inspect` عدد الكتل والإطارات المكتشفة تحت الفيديو.

> ملاحظة: التسجيل يجري بالزمن الحقيقي، ففيديو 30 ثانية يحتاج نحو 30 ثانية بعد تجهيز الصور والأصوات. OpenMontage نفسه يحتاج Python وFFmpeg، ولا يمكن تشغيله داخل Worker؛ لذلك استُخدمت نفس منهجية خط الأنابيب بأدوات المتصفح المجانية.

## الخصوصية

- المحادثات والإعدادات تُخزَّن في متصفحك فقط (`IndexedDB` و`localStorage`).
- الحساب **محلي**: بصمة رمزك السرَّي تُشتقَّ بتقنية PBKDF2-SHA256 (150 ألف دورة) ولا تُرسَل إلى أي خادم.
- رموز الربط (GitHub/Render/Facebook) يُدخِلها المستخدم وتُخزَّن في متصفحك، وتُمرَّر عند الطلب فقط إلى المزوَّد نفسه، بلا تسجيل في الخادم.
- مسح بيانات المتصفح يمحو كل ما سبق؛ صدِّر نسخة احتياطية من زر «حفظ نسخة» إن أردت الاحتفاظ بمحادثاتك.
